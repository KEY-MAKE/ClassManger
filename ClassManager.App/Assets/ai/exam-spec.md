# 试卷格式规范（用于 AI 批量改造试卷）

> **这份文档的用法**
> 把本文档 + 一份**已经能正常生成课件的示例试卷**（试题卷 + 答案解析卷各一份）
> 一起发给 AI，让 AI 参照示例、按本文档的要求，把其他试卷的 Word 改成同样的格式。
>
> 改完以后运行自检工具确认：
>
> ```bash
> python tools/check_format.py 改造后的原卷.docx 改造后的答案解析.docx
> ```
>
> 输出「体检通过」就说明格式达标了。

---

## 0. 目标是什么

程序（exam2ppt）要把试卷 Word 自动排版成讲评课件，它**不使用任何 AI**，
只靠**逐段落读文本 + 正则匹配**来判断结构。所以文档必须满足两个前提：

1. **所有结构和编号都必须是「文本」**，不能是 Word 的自动编号、图片、文本框；
2. **标题、题号、选项、答案标记的写法必须固定**，让正则能一眼认出来。

本文档规定的就是这套写法。`必须` = 不满足就会出错；`建议` = 不满足只是效果差一点。

> **理科卷注意**：公式是个例外。Word 自带公式（OMML）和图片都是能读的，
> 只有 **MathType 对象和文本框里的内容**读不到。详见 §2.9。

---

## 1. 总原则（三条）

| # | 原则 | 说明 |
| --- | --- | --- |
| 1 | **一切靠文本，不靠格式** | 加粗、居中、字号、颜色**不影响**判断（程序不读样式）；但 **Word 自动编号、文本框、图片里的字一律读不到** |
| 2 | **一段一件事** | 标题、材料、题干、每个选项、每条答案，各自独立成段，用回车分开 |
| 3 | **序号必须显式写出** | 题号、选项字母、章节序号都必须手工打出来，不能用 Word 自动编号 |

## 2. 试题卷（原卷）格式要求

### 2.1 试卷头

正文前的前几段会被当作试卷名和科目：

- **第 1 个非空段落** = 试卷全名（会成为课件封面大标题）
- **第 2 个非空段落** = 科目（会成为封面左上角的小标签）

```
✅ 正确
2026年普通高等学校招生全国统一考试（新高考Ⅱ卷）
语文
一、现代文阅读（35分）
```

- 这两行**必须短**（80 字以内），否则会被忽略。
- 「注意事项」「本试卷共X页」「考试时间150分钟」这类行**请直接删掉**：
  短于 80 字的会被误当成科目名，长于 80 字的才会被自动跳过。
- 试卷头之后**必须**紧接第一个大题标题。
- `机密★启用前`、`绝密` 这类横幅、以及单独一行的 `注意事项：` 会被自动跳过，不用特意删。

---

### 2.2 大题标题（一级标题）

**格式**：`中文数字` + `、` + 标题文字

```
✅ 正确
一、现代文阅读（35分）
二、古代诗文阅读（35分）
三、语言文字运用（20分）
四、写作（60分）
```

**判定规则**（程序侧）：

| 约束 | 值 |
| --- | --- |
| 匹配模式 | `^[一二三四五六七八九十]+、` |
| 最大长度 | 50 字 |
| 结尾 | 不能是 `。．.？！；;，,` |
| 内容 | 不能含 `。` |
| 顺序 | 序号必须**递增**，允许跳号（最多跳 2） |

```
**说明语写在同一行也可以**（真实试卷里很常见，程序会自动剥掉说明语，标签只留本体）：

```
✅ 可以，标签会自动变成「选择题」「非选择题」
一、选择题：本题共15小题，每小题3分，共45分。在每小题给出的四个选项中，只有一项是符合题目要求的。
二、非选择题：本题共4小题，共55分。
```

剥说明语的规则：**有冒号就取冒号前**（`一、选择题`），**有句号则只接受「一句话 +（N分）」这种短尾巴**。
不过为了最保险，**推荐**把说明语另起一段，标题只留短名字。

```
❌ 错误写法（不会被识别成标题）
第一部分 现代文阅读          ← 中文数字后必须是「、」
1. 现代文阅读                ← 阿拉伯数字不算大题标题
Ⅰ. 现代文阅读                ← 罗马数字不支持
（一）现代文阅读             ← 这是「小节标题」的写法，别用在材料组里
一、有关说明：本题共X小题，分值分布如下，请考生注意审题，认真作答每一个问题。   ← 冒号前太长/带逗号
```

---

### 2.3 小节标题（二级标题）

**格式**：`（` + `中文数字` + `）` + 标题文字

```
✅ 正确
（一）现代文阅读Ⅰ（本题共5小题，19分）
（二）现代文阅读Ⅱ（本题共4小题，16分）
（三）文言文阅读（本题共5小题，20分）
```

**判定规则**：最大 50 字；结尾不能是句读；不能含 `。`；
序号在**当前大题内递增**，允许跳号。

> ### ⚠️ 这是最容易出问题的一条
>
> **每一个「材料组」都必须有自己的小节标题。**
>
> 程序用一个材料组的小节标题来命名课件上的红色标签
> （「现代文阅读Ⅰ原题」「现代文阅读Ⅰ答案·续」）。
>
> 如果一个大题下有多个材料组，但**第一组没有小节标题**，
> 那么这一组的标签会退化成大题名（比如「阅读原题」而不是「现代文阅读Ⅰ原题」）。
>
> ```
> ✅ 正确：每组都有小节标题
> 一、阅读（72分）
> （一）现代文阅读Ⅰ（19分）
> 【材料…】
> 1. 下列…
> （二）现代文阅读Ⅱ（16分）
> 【材料…】
> 5. 下列…
>
> ❌ 错误：第一组漏了小节标题
> 一、阅读（72分）
> 【材料…】          ← 没有「（一）」，这组标签只能叫「阅读」
> 1. 下列…
> （二）现代文阅读Ⅱ（16分）
> ```

---

### 2.4 材料正文

写完小节标题之后、该组第一道题之前的所有段落，都会被当作**阅读材料**。

```
✅ 正确
（一）现代文阅读Ⅰ（本题共5小题，19分）
“廊桥”指的是沿桥梁全长覆有廊屋的桥，它多在我国南方山区与西北民族走廊一带使用。……
“廊桥”这个概念其实是一种当代产物。首先，“廊桥”不属于通常桥梁研究中的类型。……
（摘编自刘妍《传奇与绝技：木拱桥里的中国营造智慧》）
1. 下列对原文相关内容的理解和分析，不正确的一项是（    ）
A. 作为一种桥梁类型，廊桥属于当代产物……
```

**材料段落不能以下面这些开头**（否则会被误判成标题或题目）：

- ❌ `数字` + `.` / `．` / `、` → 会被当成题号，例如 `1. 什么是廊桥？`
- ❌ `A`~`H` + `.` / `．` / `、` → 会被当成选项
- ❌ `中文数字` + `、` → 会被当成大题标题
- ❌ `（中文数字）` → 会被当成小节标题，例如 `（一）定义`

> 材料内部如果需要小标题，**建议**改用「○」「●」「◆」或「第一」「其一」等，
> 不要用 `一、` `（一）` 这种会被占用的写法。
>
> 例外：材料里以 `一、二、三、四、` 开头且**以问号结尾**的问答句是安全的
> （程序会因「序号不递增」和「以问号结尾」两条规则跳过它），但换一种写法更保险。

### 2.5 题干

**格式**：`阿拉伯数字` + `.`（或 `．` / `、`）+ 空格 + 题干

```
✅ 正确
1. 下列对原文相关内容的理解和分析，不正确的一项是（    ）
10. 画波浪线的部分有三处需要断句，请用铅笔将答题卡上相应位置的答案标号涂黑。
23. 阅读下面的材料，根据要求写作。
```

**必须遵守**：

1. 题号必须是**阿拉伯数字**，写在**行首**；
2. 题号必须**全局连续**（1、2、3、……、23），不能跳号、不能重复；
3. **每道题都必须有题号**——原卷漏编号的题要补上；
4. 题干和选项之间**建议分段**（同一段也能识别，但分段更保险）；
5. 题干里出现 `A.` 这种字母加点的组合要小心，可能被当成选项切分点。

```
❌ 错误写法
第1题 下列…            ← 不支持「第N题」
1）下列…               ← 「1）」本工具能容忍，但规范就不要用了
１．下列…              ← 全角数字 １ 不认识
下列…                  ← 漏了题号（除非解析卷里有对应题号，否则认不出来）
```

> **第 3 条特别重要**：程序会拿解析卷里出现过的题号来兜底，
> 但**原卷里漏题号始终是高风险操作**。改造时请务必逐题检查编号连续。

---

### 2.6 选项

**格式**：`A` / `B` / `C` / `D` + `.`（或 `．` / `、`）+ 空格 + 选项内容

```
✅ 推荐写法：每个选项独立成段
1. 下列对原文相关内容的理解和分析，不正确的一项是（    ）
A. 作为一种桥梁类型，廊桥属于当代产物，它主要分布在我国南方山区与西北高原走廊一带。
B. 河北的赵州桥、北京的卢沟桥以及《水殿招凉图》中殿侧的虹桥，与地域性的传统廊桥都存在着性质上的不同。
C. 语言会随社会文化的发展而不断变化，“廊桥”一词的产生、传播也与社会变动、文化生活等密切相关。
D. “主动创造的空间”体现了中国传统建筑中的人文关怀——廊桥不仅是技术的产物，也是为人服务的空间艺术。
```

**也能容忍的写法**（但推荐上面那种）：

```
✅ 一行多个选项
A. 舜命后稷，食为政首B. 茨充为桂阳令
C. 某所大木，可以为棺D. 好为民兴利

✅ 题干和选项同一段
1. 下列说法正确的是（ ）A．甲 B．乙 C．丙 D．丁
```

**必须遵守**：

1. 选项字母必须是**半角大写 `A`~`H`**，按 `A→B→C→D` 顺序；
2. 字母后面必须有 `.` / `．` / `、` / `)` / `）` 之一；
3. **不要**写成 `(A)` 或 `（A）` —— 带左括号的会被当成「交叉引用」而跳过。

```
❌ 错误写法
（A）作为一种桥梁类型…      ← 带左括号，不认
甲. 作为一种桥梁类型…       ← 必须用 A/B/C/D
A、作为一种桥梁类型…        ← 这个其实能认（、 也支持），但推荐统一用 A.
```

### 2.7 注释与出处

单独成段，用下面任一种开头即可（会被识别为注释/出处，附在材料末尾）：

```
✅ 正确
[注]①王景，与下文的茨充、崔寔，都是汉代官吏。②醯，醋；醢，酱。
【注】抵桩：打算。
（摘编自刘妍《传奇与绝技：木拱桥里的中国营造智慧》）
（选自《燕知草》，有删改）
（节选自贾思勰《齐民要术·序》）
```

**建议**：出处放在材料正文之后、第一道题之前，单独成段。

---

### 2.8 图片

- **题目里的插图**（图/表/漫画）会被自动提取，并**内联在它原本出现的位置**——
  题干下面、材料中间、两个小问之间都能正确落位，课件题目页里直接就能看到；
- **材料组级别**的插图（整段材料配的一张图）会单独出一页「材料图」；
- 图片**不要**放太多、太大（会被等比缩放到版面里，单张最高约 3.4 英寸）；
- 图片里的**文字无法识别**——所有该读的文字都必须是可选中文本；
- 确保题目**各段落的先后顺序正确**，图片会按段落顺序插回去。

### 2.9 公式（理科试卷必读）

数学、物理、化学卷子里的公式有两种存法，程序对它们的处理完全不同：

| 存法 | 在 Word 里长什么样 | 程序怎么处理 |
|---|---|---|
| **Word 自带公式** | 「插入 → 公式」，点一下会出现虚线框，可以在框里打字 | ✅ 会完整识别：分式、根式、上下标、求和、积分、矩阵、方程组都会还原 |
| **截图 / 图片** | 一张 PNG，点不进去 | ✅ 会当作行内插图，内联到原来的位置 |
| **MathType 公式** | OLE 对象，双击会弹 MathType 窗口 | ❌ 读不到内容，会被**整块丢弃** |

**MathType 是最大的坑。** 它插进来的不是文本也不是图片，而是一个二进制对象，
程序只能看见一个空壳。如果你的卷子是用 MathType 排的，交卷前必须二选一：

- 全选 → MathType 工具栏 → **转换公式 → 转换为 Office 公式**（推荐，转完还能编辑）；
- 或者把公式连同上下文一起**截图**成图片插回去（丢可编辑性，但保险）。

#### 公式会怎么变到幻灯片上

Word 里的公式是「二维」的（分式上下叠、根号罩住一整个式子），
幻灯片上会被**拉平成一维写法**，同时把上下标做成真正的上标下标：

| Word 里的公式 | 进来以后 |
|---|---|
| $\frac{1}{2}$ | `1/2` |
| $\frac{a+b}{c}$ | `(a+b)/c` ← 分子分母有加减号时自动补括号 |
| $\sqrt{3}$ | `√3` |
| $\sqrt{a+b}$ | `√(a+b)` ← 根号下不止一项时补括号 |
| $x^{2}$ | `x²` ← 真正的上标，字号小一号、位置抬高 |
| $a_{n+1}$ | `aₙ₊₁` ← 真正的下标 |
| $x^{6-2r}$ | `x` + 上标 `6−2r` |
| $\sum_{k=1}^{n} k^2$ | `∑` + 下标 `k=1` + 上标 `n` + `k²` |
| $\int_0^1 x^2dx$ | `∫` + 下标 `0` + 上标 `1` + `x²dx` |
| 矩阵 $\begin{bmatrix}a&b\\c&d\end{bmatrix}$ | `[a，b；c，d]` |
| 方程组 | `x+y=1；x−y=3` |
| $\vec{AB}$、$\bar{v}$ | `AB`、`v̅`（组合符号只能压一个字，多字母时省略符号） |

**这就是取舍**：拉平之后单个字都看得清、能选中、能搜索、能改，
但多层嵌套的繁分式（$\frac{1}{1+\frac{1}{x}}$）会变成 `1/(1+1/x)`，不如原式直观。
**如果某道题的公式特别复杂、非竖式不可**，最省事的办法是把那一整段公式截成图片插进去——
图片会原样贴到幻灯片上，只是不能编辑了。

#### 手打公式的建议

不改公式、直接手打也完全可以，只要注意三点：

1. **上下标请用 Word 的公式，或者用「开始 → 下标」按钮**（`Ctrl + =`）。
   直接打成 `a(n+1)`、`x^2` 这种纯文本，程序只能原样照抄，看起来就是一行平字；
2. **同一个符号别混用两种写法**。比如 `√3` 和 `√3`（后一个可能是图片或别的字符），
   混着用会有一段是公式、一段是字，视觉上不齐；
3. **化学式**推荐用公式工具写（H₂SO₄ 的 2 和 4 是下标）；
   手打 Unicode 下标字符（`H₂SO₄`）也能识别，只是字体换行时容易跟正文错位。

#### 特别提醒

- 公式**不要**放在文本框里——文本框里的内容程序读不到，这一整块都会消失；
- 公式**不要**放在表格里（可以，但会被拉成好几行）；需要对齐的表格请直接截图；
- 行内公式前后**不要**加多余空格，中文和公式之间本来就该贴着排（`已知a>0，则` 比 `已知 a > 0 ，则` 更接近原卷）；
- 识别出来对不对，可以用「预览解析结构」看一眼，或者直接翻生成好的 PPT。

## 3. 答案解析卷格式要求

解析卷靠三个中文方括号标记来分区：`【答案】`、`【解析】`、`【N题详解】`、`【导语】`。
半角方括号 `[答案]` `[解析]` 也可以。

### 3.1 答案区

以 `【答案】` 开头，**必须写明题号**。

```
✅ 一行一题或一行多题都行
【答案】1. A    2. C
3.     ①. 没有覆盖全桥    ②. 路面下方（或“桥面之下”）
4. ①原文篇幅长、信息量较大，而问答文段化繁为简，可以让读者快速抓住关键信息。
②问答文段以设问形式引导读者，一问一答的形式线索清晰，针对性强，有利于答疑解惑。
5. （1）通过原文第一段的“两种考虑”可知……

✅ 题号写在标记前面也可以
17. 【答案】    ①. 骐骥一跃    ②. 不能十步    ③. 五陵年少争缠头

✅ 同一行多题，用空格分开
【答案】19. C    20. 而一经诗人的加工创制，又成了不朽的名句。

✅ 也能认（不带方括号，但后面必须跟两个以上「题号.」）
答案1.C 2.B 3.A 4.C 5.B
```

**必须遵守**：

1. **每道题都要有答案**，且题号要和原卷**完全一致**；
2. 选择题答案**只写字母**：`A`、`C`、`BC`、`CEG`（多选/断句就写一串字母）；
3. 一行里有多个题号时，题号前要有空格分隔；
4. 答案后面如果想加解释，请**移到【解析】区**，不要在答案里写「因为……」；
5. 一段答案写不完，续行**不要**再写题号（会被认为是下一题）。

```
❌ 错误写法
【答案】1. 选A                ← 多写了「选」字，但仍能兜底识别，最好只写 A
1. A                          ← 漏了【答案】标记，整段都会被忽略
【参考答案】1. A               ← 标记必须是「答案」两个字，多字不认
【答案】第一题：A              ← 必须用阿拉伯数字题号
```

### 3.2 解析区

先写一个 `【解析】` 表示进入解析区，然后**每题一个 `【N题详解】`**。

```
✅ 正确
【解析】
【导语】本文围绕廊桥展开论述，先介绍廊桥的定义、分布与建造廊屋的作用……
【1题详解】
A.“作为一种桥梁类型，廊桥属于当代产物”错误。原文第二段明确指出……
故选A。
【2题详解】
A.“是想引导读者认识到桥梁的价值……”错误。原文第二段讨论桥梁类型分类……
故选C。
```

**必须遵守**：

1. `【N题详解】` 里的 **N 必须是阿拉伯数字**，且与原卷题号一致；
2. 解析正文写在 `【N题详解】` 的**下一段**，可以多段（都会归到这道题）；
3. `【解析】` 只写一次就够，之后每题都用 `【N题详解】` 分开；
4. **建议每题都写 `【N题详解】`**。如果某题漏了，它的解析会归到上一题，内容就错位了。

```
**含小题的题**（如政治第 18 题分（1）（2））：题号取小题括号前的数字，两种写法都可：

```
✅ 推荐
【18题详解】
（1）示例：中华水文化蕴藏深刻外交智慧……
（2）①坚持权利与义务相统一的法治理念……

✅ 也能认（题号取 18）
【18（1）题详解】
```

```
❌ 错误写法
解析：1. A 错误……            ← 必须用【N题详解】分段
【第1题详解】                 ← 「第」字不能有
【1题解析】                   ← 必须叫「题详解」
```

### 3.3 导语

`【导语】` 会绑定给**它后面第一道 `【N题详解】` 的题号**，也就是该材料组的第一题。

```
✅ 正确（导语紧跟在【解析】之后、该组第一题的详解之前）
【解析】
【导语】本文围绕廊桥展开论述，先介绍廊桥的定义、分布与建造廊屋的作用……
【1题详解】
……

❌ 错误（导语放错位置，会绑到别的材料组）
【1题详解】
……
【2题详解】
……
【导语】这篇散文以“打橘子”为线索……
【3题详解】
……
```

**建议**：一个材料组写一条导语，放在该组第一题详解之前；没有也可以不写。

### 3.4 各题型写法示例

**选择题**

```
【答案】1. A    2. C
【解析】
【1题详解】
A.“作为一种桥梁类型，廊桥属于当代产物”错误。原文第二段明确指出……
故选A。
```

**多选题 / 断句题**（答案写一串字母）

```
【答案】10. CEG
【解析】
【10题详解】
“此等岂好为烦扰而轻费损哉”是一句完整的话，其后应断开……
故选C、E、G。
```

**填空题 / 补写题**（用 ①②③ 标空）

```
【答案】
3.     ①. 没有覆盖全桥    ②. 路面下方（或“桥面之下”）
【解析】
【3题详解】
①回归原文第二段……可提炼出“没有覆盖全桥”。
②定位原文最后一段……反向概括得出“路面下方”。
```

**简答题**

```
【答案】4. ①原文篇幅长、信息量较大，而问答文段化繁为简，可以让读者快速抓住关键信息。
②问答文段以设问形式引导读者，一问一答的形式线索清晰，针对性强，有利于答疑解惑。
【解析】
【4题详解】
首先明确题干要求，即分析问答文段在科学普及方面的优势，需对比原文与问答文段的差异。
然后分角度归纳：……
```

**翻译题**（小题用（1）（2）标）

```
【答案】13. （1）殷周时期的兴盛，《诗》《书》里所记述的，关键在于使百姓安定，使他们富足然后再教化他们。
（2）庐江郡不懂得用牛耕地，常常导致贫困……
【解析】
【13题详解】
（1）“要在安民”中“要”意为关键……
```

**作文题**（答案区放例文，解析区放审题立意）

```
【答案】23. 例文：
破局当守体，源远见功夫
世间种种，万象纷纭……（正文各段各占一段）
【解析】
【23题详解】
【详解】【审题】
1.材料信息要点：……
2.核心矛盾：……
```

> 注意：作文这种「答案区不放题号、后面全是正文」的写法，程序会把它归到**上一题的题号 + 1**。
> 所以作文题的答案**最好也显式写题号**：`【答案】23. 例文：`，更保险。

## 4. 硬性禁止清单

| ❌ 禁止 | 为什么 | ✅ 改成 |
| --- | --- | --- |
| 用 **Word 自动编号**（`开始-编号`）做题号 | 自动编号不在文本里，程序读到的是空，**认不出题目** | 手工打字：`1. ` |
| 用 **多级列表 / 大纲编号** 做章节号 | 同上 | 手工打字：`一、`、`（一）` |
| 题目写在 **文本框 / 表格 / 图片** 里 | 文本框和图片文字读不到；表格勉强能读但排版会乱 | 放到正文段落里 |
| 题干用 **公式编辑器/OMML** 承载文字 | 公式内容不会被识别成普通文本 | 题干文字用普通文本；公式可以保留但会被跳过 |
| 题号写成 `第1题`、`１．`（全角） | 不支持 | `1. ` |
| 选项写成 `（A）`、`(A)` | 会被当成交叉引用跳过 | `A. ` |
| 选项用 `甲/乙/丙/丁` 代替字母 | 无法提取正确项 | `A. 甲` |
| 漏写题号（靠 Word 自动编号撑场面） | 认不出题目 | 每题都写 `N. ` |
| 大题标题写成 `第一部分`、`Module 1` | 不支持 | `一、` |
| 小节标题写成 `一、`（和大题混用） | 会和大题标题冲突 | `（一）` |
| 标题、题干、选项挤在同一段里 | 容易误判 | 各占一段 |
| 解析卷里答案不写题号（只有 `A` 一个字母） | 无法对应到题 | `【答案】1. A` |
| 解析卷用 `解析：` / `答案：` 代替 `【解析】`/`【答案】` | 标记不认 | `【解析】`、`【答案】` |
| 材料正文段落以 `1.`、`A.`、`一、`、`（一）` 开头 | 会被误判成题号/选项/标题 | 换个写法或用「○」「第一」 |
| 考生须知写成 `1．答卷前……` `2．回答选择题时……` | 虽然会被自动跳过，但若排在首个大题之后就可能被当成题目 | 建议放到第一个大题标题**之前**，或直接删掉 |
| 含小题的题只写 `【18（1）题详解】` 而原卷里是第 18 题 | 能认，但题号对不上会漏 | 原卷也按 `18.` 编号，或每题都写完整题号 |

## 5. 改造流程（给 AI 的执行步骤）

请严格按下面顺序做，**不要跳步、不要合并文档**：

1. **通读示例**：先看示例的原卷和答案解析卷，理解两份文件各自的骨架（参考第 2.9 / 3.5 节）。
2. **改造试题卷**
   1. 统一试卷头：第 1 行试卷全名，第 2 行科目，删掉「注意事项」长段落；
   2. 扫一遍所有大题标题，改成 `一、` `二、` `三、` 形式，且序号递增；
   3. 扫一遍所有材料组，**确保每组都有 `（一）` `（二）` 形式的小节标题**；
   4. 把所有题号改成行首 `数字. `，并**逐题核对编号连续**（1、2、3、…、N，不跳不重）；
   5. 把每个选项改成独立一段，以 `A. ` `B. ` `C. ` `D. ` 开头，按 A→B→C→D 排序；
   6. 检查材料正文段落，**不能**以 `1.` `A.` `一、` `（一）` 开头；
   7. 把注释改成 `[注]…` 开头、出处改成 `（摘编自…）`/`（选自…）` 开头，各自单独成段；
   8. 确认没有用 Word 自动编号、没有把题目放在文本框/图片里。
3. **改造答案解析卷**
   1. 给每道题（1~N，一个都不能少）都写出 `【答案】N. …`，选择题答案只写字母；
   2. 写一个 `【解析】`，然后**每题一个 `【N题详解】`**，解析正文写在它下面；
   3. 每个材料组写一条 `【导语】`，放在该组**第一题详解之前**；
   4. 检查有没有漏题的解析，漏掉的补上；
   5. 作文题最好像这样显式写题号：`【答案】23. 例文：`。
4. **自查**：对照第 6 节清单逐条打勾。
5. **输出**：两份 `.docx` 文件（不要 `.doc`，不要 PDF）。

> **重要的取舍**：如果原文格式和本文档冲突，**以本文档为准**。
> 不要为了「保留原样」而违反规范——课件是靠规范工作的。

## 7. 附录：程序判定规则速查表

以下是程序内部的判定逻辑，写文档时可直接对照。

### 试题卷

| 元素 | 匹配模式 | 附加约束 |
| --- | --- | --- |
| 大题标题 | `^[一二三四五六七八九十]+、` | 先剥说明语（冒号前 / 「一句话+（N分）」）；不以 `？！` 结尾；序号递增（可跳 1~2） |
| 小节标题 | `^[（(][一二三四五六七八九十]+[）)]` | 同上；序号在**当前大题内**递增 |
| 题干 | `^数字(1~2位)[.．、)）]` | 题号 = 上一题 +1，**或**该题号在解析卷里出现过 |
| 漏编号题干（兜底） | 短句 + 句末标点 + 强题干句式 | 且「下一题号」必须存在于解析卷 |
| 选项 | `^[A-H][.．、)）]` | 按 A→B→C→D 递增；支持一行多个、跨段接续；前面不能是字母/数字/左括号 |
| 注释/出处 | `^[\[【〔]注` 或 `^[（(](摘编自\|选自\|节选自\|改编自)` | 附在材料末尾 |
| 图片 | 内嵌图片 | 自动提取，单独出一页 |

### 答案解析卷

| 标记 | 匹配模式 | 作用 |
| --- | --- | --- |
| 答案 | `^【答案】` / `^[答案]` | 进入答案区，按 `数字.` 切分每条答案 |
| 答案（宽松） | `^答案` 且后面跟着 ≥2 个 `数字.` | 兼容 `答案1.C 2.B 3.A` 这种写法 |
| 题号在标记前 | `^数字. 【答案】` | 同上，题号位置更灵活 |
| 解析 | `^【解析】` | 进入解析区 |
| 题详解 | `^【数字[（小题号）]题详解】` | 该题解析开始，题号取括号前的数字 |
| 导语 | `^【导语】` | 绑定到后面第一个 `【N题详解】` 的题号 |
| 泛化语法 | `【N题详解】` 之外的段落 | 归到「答案区最后出现的题号」 |
| 无题号续行 | 答案区里不带题号的行 | 归到「上一题号 + 1」（作文例文靠这个） |
| 纯答案版 | 独立成行的「参考答案」+ 之后 ≥2 行 `数字.字母` | 整份文件按 `16.①……` 切分，考生须知式的「1．答卷前…」会自动排除 |

### 常见「标题识别不到」的原因排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 某组材料标签是大题名（如「阅读原题」） | 这组漏了小节标题 | 补 `（一）xxx` |
| 某道题没被识别 | 题号漏写 / 用了自动编号 / 编号跳了 | 手工补 `N. ` |
| 选项没被识别 | 写成 `（A）` 或用了「甲乙丙丁」 | 改成 `A. ` |
| 材料里冒出多余的「题」 | 材料段落以 `1.` 或 `A.` 开头 | 改写法 |
| 整份解析卷都没识别到 | 标记不是 `【答案】/【解析】` | 换成标准标记，或套用「纯答案版」写法 |
| 答案对错了题 | 解析卷漏了某题的 `【N题详解】` | 补上 |
| 公式整块不见了 | 用了 MathType，或公式在文本框/表格里 | 转成 Office 公式，把公式放回正文段落 |
| 公式变成一行平字 | 上下标是手打的 | 用公式工具重做上下标 |

## 9. 关于排版（不影响录入，但你可能想知道）

### 9.1 你在 Word 里怎么设字体字号，都不影响成品

程序**只读文本**，不读样式。Word 里的加粗、居中、字号、颜色、字体，一律忽略；
课件里的字体字号是**固定的**，按下面这套排（与样例讲评课件《2026 年高考全国二卷语文
高考真题+讲评课件.pptx》实测对齐）：

| 元素 | 字体 | 字号 |
| --- | --- | --- |
| 左上角标签 | 黑体 | 20 pt |
| 材料、作文正文 | 楷体 | 24 pt |
| 导语 | 楷体 | 26 pt |
| 题干与选项 | 黑体 | 24 pt |
| 答案、解析 | 微软雅黑 | 24 pt（太长时自适应降到 22 / 20） |
| 封面 / 章节 / 目录标题 | 华文中宋 | 32 / 60 / 96 pt |

所以**不要**靠设小字号来「让内容更紧凑」——那样只会白费功夫。
真正决定页数的是**字数**。

### 9.2 为什么一道题有时会占两页、三页

按上面这套字号，一页能放下的内容是有上限的（一页正文区约 6.3 英寸高、
12.4 英寸宽）。常见情况：

| 情况 | 程序的做法 |
| --- | --- |
| 题目短、答案短 | **一页搞定**：题目在上，答案面板贴底悬浮，点一下才浮现 |
| 题目长、答案短 | 题目占满一页（多出来的接「原题·续」），答案面板贴在题目最后一页 |
| 题目长、答案也长 | **分两页**：题目页 + 「答案解析」页。样例讲评课件也是这么排的 |
| 答案特别长 | 「答案解析」再接「答案解析·续」 |

一句话：**想少出页、想让答案和题目出现在同一页，就把内容写短**——
尤其是「解析」，它是页数的主要来源。

### 9.3 插图会跟着段落走

题目里的插图按**段落顺序**插回原位。所以改造时**不要打乱段落顺序**，
也不要把图挪到题干前面——否则图会跑到奇怪的位置。

## 10. 关于「标题检测」的常见疑问

**Q：为什么程序不能直接按标题样式（Heading 1/2）来判断？**

可以，但不可靠：实际收到的试卷里，90% 的标题根本没有套用样式，
而是「加粗 + 居中」或者干脆就是普通段落。
所以程序只认**文本里的序号**（`一、` `（一）`），这样最稳定、也最容易由 AI 批量改造。

**Q：材料里出现「一、什么是廊桥？」会不会被当成标题？**

不会。程序有两条规则挡住了它：标题序号必须**递增**（前面已经出现过「一、」了），
且标题不能**以问号结尾**。但如果材料内部需要小标题，仍建议用「○」「第一」等写法，最保险。

**Q：原卷和答案解析合成一个文件行不行？**

**不建议**，请保持两份分开的文件（这也正是常见教辅「原卷版」和「+答案」两个文件的形式）。
合成一份时，解析部分会被当成试题正文，污染题干和材料，排版结果会很乱。

**Q：一套卷子分成了多个文件（如阅读卷、作文卷）怎么办？**

请**合并成一个试题卷文件**。程序按全局题号匹配，拆开会导致题号对不上。
