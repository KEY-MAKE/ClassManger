## 0. 项目信息

| 项 | 内容 |
|---|---|
| 项目名称 | `class_manager`（ClassManager） |
| 原始需求 | 将单文件 Python + Tkinter 程序 `班级管理系统.py`（1904 行，作者 K.，v1.0）**用 C# + WPF-UI 完全重做**，要求「注意设计」 |
| 技术栈 | C# / .NET（自包含部署）/ WPF + WPF-UI（Fluent 风格）/ MiniExcel（Excel 解析） |

**原始需求复述**：原程序是一个班级管理工具，包含「点名系统」和「座位管理」两大模块，支持导入成绩单、随机/顺序/只点未到三种点名、可视化座位编排（三种自动算法 + 手动调整）、座位表导出（xlsx / 文本打印 / 图片）。现在要用 C# + WPF-UI 重做一遍，界面要「注意设计」（美观、现代、克制）。

## 1. 产品目标与设计原则

### 1.1 产品目标

1. **功能 100% 对标原版**：原 Python 程序的全部可用功能（含边界行为）在新版中均可复现，用户切换到新版后无功能缺失感。
2. **零门槛部署与安装**：目标机器无需预装 .NET 运行时；程序自带安装向导，双击即用，且可在程序内一键卸载，全程不依赖外部安装器。
3. **现代且克制的界面**：采用 Fluent Design / WPF-UI 视觉语言（Mica 材质、圆角、留白），替代 Tkinter 的粗糙观感，同时保证信息密度合理、动效不喧宾夺主。
4. **轻量与快速**：体积可控、冷启动迅速，满足「一个班级工具随手打开」的使用场景。
5. **稳定单机体验**：数据与设置本地持久化，异常有明确提示，程序不会因重复启动产生多窗口混乱。

### 1.2 设计原则（回应「注意设计」）

| 原则 | 说明 |
|---|---|
| Fluent / WPF-UI | 使用 `WPF-UI`（FluentWPF）控件库，控件（按钮、卡片、对话框、导航）统一 Fluent 语言，避免手写原生样式 |
| Mica / Acrylic 材质 | 主窗口使用 Windows 11 Mica 背景（系统不支持时降级为纯色），呈现「现代系统应用」观感 |
| 明暗主题 | 支持 Light / Dark，并可选「跟随系统」；默认与系统当前主题一致 |
| 留白与信息层级 | 用间距、字号、字重建立层级；主操作（点名/排座）视觉突出，次要信息降级为中性文字 |
| 动效克制 | 仅使用 150–250ms 的过渡（导航切换、结果弹出淡入）；**不做炫技动画**，不阻塞操作 |
| 信息密度 | 表格、座位画布等高频信息区保持适中密度，避免大卡片大留白导致一屏信息过少 |
| 一致的状态反馈 | 所有导入/导出/错误均落到统一的状态栏 + Toast/InfoBar，禁止无提示的静默失败 |
| 键盘可达 | 关键操作（导入、点名、退出）提供快捷键，回车/空格可触发主按钮 |

## 4. 信息架构与 UI 设计稿描述

### 4.1 窗口容器选型（结论）

**选用 `FluentWindow` + `NavigationView`（左侧导航）作为主壳；不再使用 Tkinter 的 TabView 顶部标签。**

理由：
1. WPF-UI 的 `NavigationView` 是 Fluent 应用的官方导航范式，天然支持左侧图标 + 文字、选中态高亮、Mica 背景协调，比顶部 TabView 更「像现代系统应用」。
2. 两个模块（点名/座位）体量较大且各自有独立工具链，左侧导航能让内容区获得更大的横向空间（座位画布尤其吃宽度）。
3. NavigationView 便于后续扩展（如未来加「设置」「帮助」页），扩展成本低。

> 若架构师实现成本敏感，可退化为「FluentWindow + 顶部 TabView」，功能不受影响；但推荐 NavigationView。**此项列入待确认 Q3。**

```
│ ▸ 设置(选) │  │ (可滚动)     │                              │   │
│          │  └─────────────┴──────────────────────────────┘   │
├──────────┴───────────────────────────────────────────────────┤
│ [状态栏] 就绪 - 请导入班级成绩单                                  │
└──────────────────────────────────────────────────────────────┘
```

- **标题栏**：Windows 11 可用时使用 `FluentWindow` 的 TitleBar 扩展（软件名+作者在左），右侧放班级信息胶囊 + 关于按钮。
- **导航区**：NavigationView 左侧，固定 4 项以内。
- **状态栏**：固定在窗口最底部，始终可见（对应原 `status_bar`）。

### 4.3 点名系统页 - 区域划分

| 区域 | 内容 | 控件选型 |
|---|---|---|
| 左控制栏（宽 ~260） | 导入成绩单 / 随机点名 / 重置点名 / 点名统计（按钮组）+ 点名模式单选 + 统计卡片（总/已点/未点）| `Button`（主按钮用 Fluent Accent）、`RadioButtons`、`Card` + 计数文本 |
| 右上部 | 学生名单 + 搜索框 | `DataGrid`（或 `ListView` + 列）+ `TextBox`（搜索，带 placeholder）|
| 右下部 | 点名结果大字号显示 | 大号 `TextBlock`（如 32–40px，Accent 色），居中 |
| 弹窗 | 点名统计 | `ContentDialog`（WPF-UI）或独立 FluentWindow |

- 未导入时：按钮禁用态 + 右侧用空状态页（§4.6）。

### 4.4 座位管理页 - 区域划分

| 区域 | 内容 | 控件选型 |
|---|---|---|
| 左控制栏 | 布局设置（行/列数字输入 + 更新布局）、自动排座三种按钮、手动调整说明、输出三项（保存/打印/导出图片）| `NumberBox` / `Button` / `Card` |
| 右上部 | 学生按钮列表（横向滚动，文案「姓名 (成绩分)」，已排座变绿）| `ItemsRepeater` / `WrapPanel` + `ScrollViewer(Horizontal)` |
| 右下部 | 座位表画布（座位矩形+课桌+椅子+过道+讲台+黑板）| `Canvas`（承载自绘图形）；或 `ScrollViewer` + `Canvas`，中键平移 |

- **座位画布实现建议**：用 `Canvas` + 自绘 `Shape`/`DrawingVisual`（或 `OnRender`），每座位绑定点击命中；滚动用 `ScrollViewer`，中键拖动平移通过 `MouseMove` + `TranslateTransform` 实现。
- 讲台/黑板置于座位网格上方正中；过道绘制在中间列位置（`cols/2`）。

### 4.5 关键控件选型汇总

| 场景 | 选型 | 说明 |
|---|---|---|
| 学生名单 | `DataGrid` | 支持列宽、排序、隔行底色；状态列用模板列渲染 ✅/⏳ |
| 学生按钮列表 | `ItemsRepeater`（或 `WrapPanel`）| 支持横向滚动、选中高亮、动态变绿 |
| 座位表 | `Canvas` + 自绘 | 需像素级控制，`DataGrid` 不适用 |
| 统计卡片 | WPF-UI `Card` + `TextBlock` | 统一圆角与阴影 |
| 弹窗 | WPF-UI `ContentDialog` / `FluentWindow` | 统一 Fluent 外观 |
| 提示 | `InfoBar` / `Snackbar` | 成功/警告/错误分级 |
